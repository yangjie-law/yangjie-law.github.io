# Jie Yang — Personal Academic Website

Personal academic homepage of **Jie Yang (杨洁)** — Ph.D. in Law (Environmental Law), University of Copenhagen; Assistant Professor at Harbin Normal University.

**Live site:** https://yangjie-law.github.io/

Research areas: Environmental Law · Circular Economy Law · EU Law · Comparative Law

## Structure

```
├── index.html      # 单页学术主页（中英双语切换）
├── style.css       # 样式
├── favicon.svg     # 网站图标
├── assets/
│   └── photo.png   # 个人照片
├── robots.txt      # 搜索引擎抓取规则
├── sitemap.xml     # 站点地图
└── .nojekyll       # 跳过 Jekyll 处理
```

## 如何更新内容

直接编辑 `index.html` 中对应区块的文本，commit 并 push 到 `main` 分支即可，
GitHub Pages 会在 1–2 分钟内自动重新发布。

## 搜索引擎收录（SEO）

页面已内置：meta description / keywords、Open Graph、JSON-LD(Person) 结构化数据、sitemap.xml、robots.txt。
发布后建议到 [Google Search Console](https://search.google.com/search-console) 提交 `https://yangjie-law.github.io/sitemap.xml` 加速收录。
